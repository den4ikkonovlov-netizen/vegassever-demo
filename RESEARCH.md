Дополнительные референсы пользователя:

- https://china-firework.ru/ — повторно изучен для полной переработки хиро: HTML, CSS и JS, затем работающая страница в отдельном Edge. В исходных стилях `mainscreenLayerMask` раскрывает диагональную маску с наклоном −23.6°, `mainscreenLayerWrapper` и `mainscreenLayerBackground` двигают изображение навстречу маске. ## Проверка

Автоматические локальные проверки: синтаксис JavaScript; расчёт цен по обе стороны 10.12.2026; вместимость; отбрасывание некорректных параметров; наличие файлов, якорей и JS-целей; JPEG/font-сигнатуры; отсутствие inline-обработчиков и нежелательных сетевых обращений из кода сайта; разрешён только запрошенный виджет карты; безопасные внешние ссылки. Локальный сервер отвечает HTTP 200.

После прямой просьбы пользователя искать другой способ просмотра запущен отдельный тестовый Edge/Playwright. Проверены хиро, компактный выбор всех шести предложений и карта при ширинах 1440, 1024, 768, 390 и 320 px. Проверены непрерывное вращение шара после вступления, остановка анимации при `prefers-reduced-motion`, загрузка снимков, переключение предложений клавиатурой и мышью, галерея, расчёт, диалоги и отсутствие горизонтального переполнения. По результатам исправлены сетка вступительного блока и 2-пиксельный перелив на экране 320 px; у Яндекс Карты указаны точные координаты здания. Снимки и протоколы — в `qa/`, тестовые скрипты не входят в `dist/`.

CSS нового хиро разобран lightningcss без ошибок. Восемь групп базовых проверок `verify.cjs` проходят. Публикация не подтверждена: Sites повторно сообщает, что ранее созданный проект не найден.
