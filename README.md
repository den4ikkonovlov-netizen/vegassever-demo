# Вегас — время для своих

Презентационная концепция сайта кинокафе «Вегас» в Северодвинске. Подготовлена для предложения услуги владельцу заведения. Факты проверены по сообществу ВКонтакте 19 октября 2026 года.

## Открыть сайт

Из этой папки: `npm start` (или `node serve.mjs`), затем открыть http://127.0.0.1:4173/.

Также можно запустить файл `Открыть сайт.ps1` из родительской папки. Сервер слушает только локальный компьютер. Внешних зависимостей и установки npm-пакетов нет.

## Публикация

Публичная версия разворачивается на GitHub Pages из папки `dist/` при отправке изменений в ветку `main`. Настройка — в `.github/workflows/pages.yml`. В репозиторий входят исходники и готовый сайт; тестовые снимки, исследовательские оригиналы и локальная конфигурация `.openai/` исключены. Это демонстрационная версия, что отмечено внизу страницы.

## Файлы

- `dist/index.html` — готовая страница.
- `dist/styles.css`, `dist/sections.css`, `dist/catalog.css` — базовые стили, разделы и компактный каталог.
- `dist/hero.css` — композиция первого экрана, последовательность раскрытия, крепление шара и эффекты кнопок.
- `dist/disco.js` — локальная отрисовка зеркальных плиток на вращающейся сфере.
- `dist/app.js` — данные залов, расчёт стоимости, подготовка сообщения, галереи и меню.
- `dist/assets/` — локальные фото гостей и интерьеров, шрифты.
- `build-catalog.cjs` — создаёт выбор шести предложений и первый экран подробностей из данных `app.js`.
- `RESEARCH.md` — источники, проверенные условия и роль референсов.
- `verify.cjs` — проверки стоимости, файлов, ссылок и базовых ограничений безопасности. Запуск: `npm run check`.

## Что работает

Все шесть предложений каталога ВК показаны в одном компактном выборе: пять залов и пакет «Романтический вечер». Название, вместимость и цена каждого видны сразу; при выборе меняются фото, описание, оснащение и действия в одной панели. В галереях 14 качественных снимков интерьеров; ещё один официальный снимок иллюстрирует романтический пакет. Для каждого предложения есть ссылка на исходную карточку. Расчёт аренды зависит от даты и длительности: с 10 декабря 2026 применяются новые цены из ВК. Подготовка сообщения не оформляет бронь и ничего не отправляет автоматически. Пользователь копирует текст и отправляет его сам. Есть звонок, интерактивная Яндекс Карта и вопросы.

## Данные и безопасность

Нет сервера приёма заявок, базы данных посетителей, паролей и собственной аналитики. Выбор в калькуляторе хранится только в памяти страницы. Фото и шрифты локальные. Яндекс Карта загружается при прокрутке к ней; её виджет может собирать данные по правилам Яндекса, что указано рядом с картой и в заметке о конфиденциальности. Скрипты используют фиксированные данные и `textContent`, а не HTML-вставки. Установлена CSP, внешние ссылки имеют `noopener noreferrer`. Файл `_headers` содержит защитные HTTP-заголовки для поддерживающего их статического хостинга; их применение нужно проверить на выбранном хостинге. Публичный текст и фотографии сайта по природе доступны для чтения и сохранения.

## Ограничения и выпуск

Визуальная проверка выполнена в отдельном тестовом Microsoft Edge через Playwright. Проверены размеры 1440, 1024, 768, 390 и 320 px, последовательность хиро, навигация, фотографии и переключатели галерей, выбор зала, калькулятор, диалоги и мобильная вёрстка. Карта загрузилась в тестовом браузере и показывает точку Беломорского проспекта, 44А. Скриншоты и результаты находятся в `qa/`. В проверенных сценариях нет ошибок JavaScript и горизонтального переполнения. Safari и Firefox отдельно не проверялись.

Перед официальным запуском согласовать с заведением содержание, фотографии, цены, реквизиты и режим работы. Подвал сейчас честно обозначает презентационную концепцию. `robots.txt` запрещает индексацию демоверсии. После утверждения можно снять пометку и разрешить индексацию.

## Дизайн

Первый экран построен на контрасте полуночного синего, малинового и кораллового света. Главный акцент — крупное «ВАШ.», под ним светлая лаймовая кнопка. В кадре настоящие гости, билет с количеством залов и зеркальный шар. Механика China Firework разобрана по исходникам и работающей странице: диагональная маска, встречное движение изображения, задержки текста, растекающаяся заливка кнопки. Реализация для «Вегаса» самостоятельная, без сторонних анимационных библиотек. Вступление заканчивается менее чем за четыре секунды. Затем зеркальные плитки движутся вокруг вертикальной оси шара; трос тянется к креплению вверху хиро. SVG остаётся запасным изображением, если Canvas недоступен. Кнопка «Ещё раз?» повторяет вступление. `prefers-reduced-motion` останавливает движение.

Остальные разделы развивают палитру первого экрана: глубокий сливовый, сиреневый, лаймовый, розовый и светлый лиловый. Большой снимок живого праздника открывает повествование, далее идут компактный выбор залов с реальными интерьерами и цветные карточки активностей. Текстовый курсор режима навигации по странице скрыт вне полей ввода; выделение текста и работа формы сохранены. Повторяющийся декоративный значок убран. Кириллические Onest и Unbounded загружаются локально. Подробности о референсах — в RESEARCH.md.
